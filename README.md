# 🎓 Training 2026 Dashboard

## 📌 Project Overview

Training 2026 Dashboard is an interactive, responsive web interface developed using **HTML5, CSS3, and Vanilla JavaScript**, with the assistance of AI tools.

The project aims to recreate the dashboard demonstrated in the provided `uiTask.mp4` reference video while applying modern web development techniques, responsive layouts, animations, and interactive components.

## 🚀 Features

- **Responsive Dashboard:** Adapts to different screen sizes using CSS Grid and Flexbox.
- **Resizable Sidebar:** Allows users to adjust the sidebar width by dragging its edge.
- **Sidebar Navigation:** Includes 15 navigation items with colorful icons and hover effects.
- **CSS Animations:** Features floating translucent squares on a dark-red background.
- **Anatomical Heart Animation:** Displays an animated heart with mouse-based zoom controls.
- **Independent Scrolling:** The sidebar and educational article can scroll independently.
- **Dynamic Content Management:** Add, remove, and clear numbered updates.
- **Language Switching:** Supports English and Arabic with LTR and RTL layouts.
- **Floating Add Button:** Provides quick access to the Add Content functionality.
- **Accessibility:** Includes semantic HTML elements and reduced-motion support.

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the dashboard and its interactive features.

No installation or build process is required.

## 🖱️ How to Use

- **Sidebar:** Navigate between sections and resize the sidebar by dragging its border.
- **Add Content:** Click the header button or floating plus button to create an update.
- **Remove Content:** Remove individual updates using their delete buttons.
- **Clear Content:** Delete all updates and reset the counter.
- **Language:** Switch between Arabic and English.
- **Heart:** Use the mouse wheel to zoom, click to enlarge, and double-click to reset.
- **Article:** Scroll through the educational content without moving the animation panels.

## 🎯 Project Requirements

The implementation follows these main requirements:

- HTML, CSS, and JavaScript in a single file.
- CSS Grid-based layout.
- Semantic HTML structure.
- No more than two `div` elements.
- Responsive design.
- Interactive JavaScript functionality.
- Visual similarity to the provided reference video.

## 📋 Notes

The anatomical heart uses an embedded animated visual with limited mouse interactions. It is not a fully interactive 3D anatomical model.

The sidebar navigation provides visual selection feedback rather than separate functional editors.
